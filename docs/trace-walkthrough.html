What the trace proves

Security

The id is injected, not chosen

Every invoice tool call shows args: {}. The verified customer_id is filled from state, so the model can't read another customer's data — even if asked.

Memory

Turn 1 writes, turn 2 reads

create_memory saved "The Rolling Stones"; next turn load_memory surfaced it, turning a vague "my preferences" into a real lookup.

Routing

One turn, both agents

The supervisor delegated to invoice and music sequentially because each agent answered only its own part — then it merged the two.
